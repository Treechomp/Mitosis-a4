# A Sectid colony besieging a Faeling crystal.
# Tests the objective path end to end: a structure is acquired without going through prey
# targeting, walked to, hit with the surface-to-surface reach, and destroyed — and the crystal's
# linked Faeling never comes back.
#
# The crystals are planted ON TOP OF the colony, and that is now load-bearing. Sectid
# StructureAggression is 0.15 — a structure must be within 0.15x the distance of the prey the
# swarm would otherwise take, and with no prey in sight that comparison uses the swarm's own seek
# radius (45), so an UNPROVOKED Sectid is distracted only by a structure within about seven tiles.
# That is deliberate: unprovoked structure-breaking in the opening minutes is what the whole-game
# invariant forbids. Retaliation is the other path (x8 bias), and it needs someone to attack the
# colony first, which nothing here does.
#
# Crystals are also 1,600 HP now, not 400 — a crystal is the most permanent thing in the game and
# every one lost shrinks a twelve-member faction forever. Hence the longer budget.
#
# Watch latest_events.csv for structure_damaged -> structure_destroyed -> crystal_destroyed.
